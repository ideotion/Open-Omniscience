# Archive — embedded historical ledgers lifted out of `docs/FUTURE_DEVELOPMENTS.md`

Records, not status. Each file below was a `## ` section of `docs/FUTURE_DEVELOPMENTS.md` that had
stopped being *design intent* — the thing that document exists to hold — and become a dated LOG of what
was observed on a particular day. Four of them together ran to 284 lines, which is why a reader looking
for the *why* behind a feature had to scroll past three months of field notes to reach it.

**Moved verbatim on 2026-09-07** (A4(b), the recommended default of question A4 in
`docs/plans/2026-09-06-repo-analysis/QUESTIONS_FOR_THE_MAINTAINER.md`): nothing was condensed, reworded
or dropped, and the move was checked line-by-line against the pre-move file — every non-blank line of the
original is still present, here or in the source document. `docs/FUTURE_DEVELOPMENTS.md` keeps each
section's heading with a pointer to the file it moved to, so an inbound reference of the form
*"FUTURE_DEVELOPMENTS.md → CONSOLIDATED TO-DO"* — several archived session briefs carry exactly that —
still lands somewhere that says where the content went.
