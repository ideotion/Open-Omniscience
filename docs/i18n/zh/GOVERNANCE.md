# 治理与可接受的使用

Open Omniscience 是一个**问责权力**的工具，它帮助人们如实地看清公开信息的*结构*。正因为这种能力很强大，本文档明确说明：这个工具用于什么、它不会越过哪些底线，以及它打算如何在发展中保持可信。这是项目伦理的一部分，而不是事后的补充。

## 它用于什么

- **调查新闻与公共利益研究**，对象是*已公开*的媒体、机构、市场和法律——呈现可测量的结构（所有权集中、协同/回声、新颖性、框架、随时间的变化），供人来判断。
- **信源保护与可复现性**——本地优先、可离线运行，并带有可发现篡改的来源记录，使研究结论经得起辩护。经过哈希链接、签名的证据保管链（chain of custody）记录是**可选开启**的（默认关闭——它会为每篇文章增加少量签名开销）：当某个案件需要证据完整性时，在**设置 → 证据保管链（Chain of custody）→「采集时自动记录」（Auto-log on ingest）**中启用（或设置 `OO_CUSTODY_ON_INGEST=1`）。在启用之前，来源信息（信源、抓取时间、内容哈希）仍然随每篇文章保存，并且可以按需生成签名的证据包。

## 双重用途的红线（在构造上不存在，不可配置）

能够揭露协同影响行动的同一套技术，落入不当之人手中，也可能被用来针对普通人。让本工具保持为*问责*手段而非*监控*工具的那条界线是明确的，它由**架构**守住，而不是由用户可以切换的某个设置守住：

1. **不追踪私人个体。** 本工具分析的是*已公开的信源*（媒体、机构、公开文件）。它**不会**为私人建立画像，`src/compliance/gdpr.py` 就是这道护栏。知名度（Prominence）衡量的是*已被报道的公众人物所获得的报道量*——是关注度，绝不是重要性或功绩。
2. **不进行生物特征识别。** 不做人脸、声音或步态识别。永远不做。
3. **不采集私密渠道。** 不涉及私信、私密信息流、截获的消息或非公开数据。语料库由用户能够合法且合乎伦理地访问的信源构建。
4. **不做自动裁决。** 没有真实性/可信度/"信任"评分，没有"有偏见"/"假新闻"标签。本工具呈现的是*附带方法与注意事项的测量结果*；由人来下结论。（在代码中强制执行：`assert_no_score_fields`。）
5. **没有中央服务器、账户或遥测。** 除用户指示的抓取外，没有任何东西离开用户的机器。不存在可供查扣或传唤的用户数据"蜜罐"。
6. **不悄悄过滤信源或降低其权重。** 关于覆盖情况的事实会被*呈现*；任何降低传播的操作都由用户施加、有明确标记且可撤销——只呈现，绝不强制。

这些在代码能做到的范围内被强制执行：一个 CI 测试（`tests/test_repo_invariants.py::test_red_lines_not_crossed`）会在代码库中出现被禁止的能力（生物特征识别、个人追踪）时使构建失败。测试只是绊线，而不是证明——真正的保证是文化与审查。

## 法律与伦理立场

- 这是一个**研究镜像**，不是权威信源，**也不是法律意见**；每条记录都链接回其出处。
- 默认采用**合乎伦理的访问**方式：robots.txt 失败即关闭、按主机限速、表明身份的 User-Agent、保存署名与来源信息。（用户可以启用*受保护（Protected）*抓取——代理 + 通用 UA，但应用自身发往 Wikimedia 的 Wikipedia、Wikidata 和转储请求除外，因为 Wikimedia 的 API 政策要求每个工具表明身份——以便在调查强大对象时保护信源或自己；这是保护信源的新闻职责，是经过深思熟虑并有记录的选择，绝不是悄然生效的默认设置。）
- **尊重许可证和版权**；保存来源信息和所需的最少数据；履行各司法辖区的数据保护义务。

## 独立性与资金

本工具被有意设计为**运行成本低廉**（本地运行，无需基础设施），以便保持**独立**。如果项目将来接受资助，它将避免被任何单一资助方或议程所左右，透明地做出决策，并且绝不为迎合赞助方而歪曲"虚假信息"的定义。本项目所做的最具政治性的选择，就是保持小型、本地化、不可被俘获。

## 抵御滥用

没有任何工具能够防止所有滥用，我们也不会假装可以。我们的抵御是结构性的：上述红线、本地优先的设计（没有可被大规模滥用的中央数据）、拒绝做出裁决，以及开放（任何人都可以检查、派生和审计）。如果你认为项目正被引向越过某条红线，请提交 issue——可被质疑正是关键所在。

## 如何做出决策（意向）

目前这是一个处于早期、只有一位维护者的项目。在公开的 `0.1` alpha 版本之前，我们打算：进行**外部安全与伦理审查**，转向决策透明的**多维护者治理**，并制定一份让贡献者受红线约束的**贡献公约**。在此之前，本文档即为正式承诺。
