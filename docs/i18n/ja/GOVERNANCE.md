# ガバナンスと許容される利用

Open Omniscience は、人々が公開情報の*構造*を誠実に見られるよう支援することで、**権力に説明責任を果たさせる**ためのツールです。その能力は強力であるため、本文書は、このツールが何のためにあるのか、越えない一線はどこか、そして成長しながらどのように信頼に値する存在であり続けようとしているのかを、はっきりと述べます。これはプロジェクトの倫理の一部であり、後付けではありません。

## 何のためのツールか

- **調査報道と公益のための研究**。対象は*公開済み*のメディア、機関、市場、法律であり、人間が判断するための測定可能な構造（所有の集中、協調／反響、新規性、フレーミング、時間経過による変化）を浮かび上がらせます。
- **情報源の保護と再現性**。ローカルファーストでオフライン動作が可能であり、改ざんの痕跡が残る来歴によって、得られた知見を擁護できます。ハッシュチェーンで連結された署名付きの証拠保全記録（chain of custody）は**オプトイン**です（既定ではオフ。記事ごとに小さな署名コストが加わるため）。事案で証拠としての完全性が重要になるときに、**設定 → 証拠保全（Chain of custody） → 「取り込み時に自動記録（Auto-log on ingest）」**（または `OO_CUSTODY_ON_INGEST=1`）で有効にしてください。有効にするまでの間も、来歴（情報源、取得時刻、コンテンツのハッシュ）はすべての記事に付随し、署名付きの証拠バンドルは必要に応じて作成できます。

## デュアルユースのレッドライン（構造上存在せず、設定で変更できない）

協調的な影響工作を暴く技術そのものは、悪意ある者の手に渡れば一般の人々に向けられる可能性があります。このツールを*監視*の道具ではなく*説明責任*の手段にとどめる一線は明確であり、それはユーザーが切り替えられる設定ではなく、**アーキテクチャ**によって守られています。

1. **私人の追跡はしない。** このツールが分析するのは*公開された情報源*（報道機関、機関、公文書）です。私人のプロファイリングは**行わず**、`src/compliance/gdpr.py` がそのガードレールです。注目度（Prominence）が測るのは*すでに報じられている公人の報道量*であり、注目の度合いであって、重要性や功績では決してありません。
2. **生体認証による識別はしない。** 顔、声、歩容の認識は行いません。今後も決して。
3. **非公開チャネルの取り込みはしない。** DM、非公開フィード、傍受されたメッセージ、非公開データは扱いません。コーパスは、ユーザーが合法的かつ倫理的にアクセスできる情報源から構築されます。
4. **自動的な判定はしない。** 真実性／信頼性／「信用」のスコアも、「偏向」／「フェイク」のラベルもありません。ツールが示すのは*手法と注意書きを伴う測定値*であり、結論を出すのは人間です。（コードで強制：`assert_no_score_fields`。）
5. **中央サーバー、アカウント、テレメトリーはない。** ユーザーが指示した取得以外、ユーザーのマシンから外へ出るものはありません。押収や開示命令の対象となるユーザーデータの集積（ハニーポット）は存在しません。
6. **情報源の無言のフィルタリングや重み下げはしない。** カバレッジに関する事実は*表示*されます。拡散の抑制はすべてユーザーが適用し、明示され、元に戻せます。表示はしても、強制はしません。

これらはコードで可能な限り強制されています。CI テスト（`tests/test_repo_invariants.py::test_red_lines_not_crossed`）は、禁止された機能（生体認識、個人の追跡）がコードベースに現れるとビルドを失敗させます。テストは仕掛け線であって証明ではありません。本当の保証は文化とレビューです。

## 法的・倫理的な立場

- **研究用のミラー**であり、正式な情報源ではなく、**法的助言でもありません**。すべての記録は元の出典にリンクしています。
- 既定で**倫理的なアクセス**を行います。robots.txt はフェイルクローズ、ホストごとのレート制限、身元を示す User-Agent、帰属表示と来歴の保存。（ユーザーは、強力な対象を調査する際に情報源や自分自身を守るため、*保護（Protected）*取得 — プロキシ＋汎用 UA。ただし、アプリ自身が Wikimedia に送る Wikipedia、Wikidata、ダンプのリクエストは除きます。Wikimedia の API ポリシーは各ツールに名乗ることを求めているためです — を有効にできます。これは情報源を守るという報道上の義務であり、意図的に選択され、文書化されるものであって、決して無言の既定動作ではありません。）
- **ライセンスと著作権を尊重**します。来歴と必要最小限のデータを保存し、各法域のデータ保護義務を守ります。

## 独立性と資金

このツールは、**独立**を保てるよう、意図的に**低コストで運用できる**ようにしています（ローカル動作、インフラ不要）。プロジェクトが将来資金を受ける場合でも、特定の資金提供者や思惑に取り込まれることを避け、透明に意思決定を行い、スポンサーの都合に合わせて「偽情報」の定義を曲げることは決してありません。このプロジェクトが下す最も政治的な選択は、小さく、ローカルで、取り込まれない存在であり続けることです。

## 悪用への耐性

あらゆる悪用を防げるツールは存在せず、そうでないふりもしません。私たちの耐性は構造的なものです。上記のレッドライン、ローカルファーストの設計（大規模に悪用できる中央データがない）、判定を下さないこと、そして公開性（誰でも検査、フォーク、監査できる）です。プロジェクトがレッドラインを越える方向へ導かれていると考える場合は、issue を立ててください。異議を唱えられることこそが要点です。

## 意思決定の方法（方針）

現時点では、これは初期段階の、メンテナーが一人のプロジェクトです。公開 `0.1` アルファの前に、私たちは次のことを予定しています。**外部によるセキュリティと倫理のレビュー**、透明な意思決定を伴う**複数メンテナーによるガバナンス**への移行、そして貢献者をレッドラインに拘束する**コントリビューション規約**です。それまでは、本文書が正式な約束です。
