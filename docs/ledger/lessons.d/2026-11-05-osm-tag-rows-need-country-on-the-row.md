## 2026-11-05 — a change row for a thing that can disappear must carry what the thing's own row would have said: the country and the event, written at the moment it is known (R428, the OSM tag rows, B2)

**What was found.** S06-01 S2 asked for "the object disappeared row that surface 3 reads", and S05-04's `osm_tag_changes` (key NOT NULL; added / removed / modified; no country) could not carry it. The failure is structural, not a missing feature: a deleted object's `osm_objects` row is deleted in the same transaction, so after the apply nothing joins that change to a country, and nothing says whether keys vanished because the object was deleted, because its tags stopped qualifying, or because someone removed a tag. A trend "closures by country" computed from the table as it stood would have been unanswerable, and the tempting fix (join to the objects table at read time) silently drops exactly the rows that matter.

**The rule.** When a change log is written next to the thing it describes and the thing can be removed, the log row must carry, at write time, every fact the removed row would have supplied (here `country_alpha3`) and the event that explains the change (`created` / `deleted` / `left_class`; NULL for an ordinary key change). Add them as NULLABLE columns so the lane's additive path (`store.add_missing_columns`) reaches existing files with no backfill: old rows say NULL, which is what "this build did not know" means. Also read the OLD value before the write or delete, not after (the positive test fails when the order is swapped), and refuse to invent an old state: a modify of an object the store never held writes no rows, because every key would read "added" and that is a claim about a past nobody saw (counted `tags_unknown_before`, so the gap is a number and not silence).

**Where enforced.** `tests/test_osm_tag_rows.py`: exact rows from the fixture's stored tags, the negative-space fixture (empty diff, unkept classes only, tag-neutral modify), and one test per refusal; each guard was mutation-checked by name (ten mutants, all killed).
