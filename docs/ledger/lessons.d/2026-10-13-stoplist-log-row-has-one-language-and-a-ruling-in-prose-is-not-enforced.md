## 2026-10-13 — A KEYWORD-LOG ROW CARRIES ONE LANGUAGE, SO "NOT CONTENT ELSEWHERE" MEANS "NO ROW ELSEWHERE", AND A STANDING REFUSAL WRITTEN IN PROSE IS NOT A REFUSAL (stoplist batch 2, #1352)

(1) **The batch tool's `content_elsewhere` guard reads the log's rows, and a row is keyed by the term with the term's DOMINANT language.** A word that is a German preposition in 934 articles and "sea" in 71 Indonesian ones has one row, `de`, and no `id` row exists to be found: the guard passed `laut`. The rest of the evidence was on the row all along, in `language_signature` (articles per language that read the term), which no code used. The tool now prints it for every word ("also read in articles tagged id (71)") and decides nothing from it, because the list is noisy in the other direction too: an English-tagged article quoting `trotz` puts `en (40)` on a plain German function word, and a threshold of ten articles in another language that stops `laut` also stops 60 of the 295 first-run candidates that had a row. The rule that works is a person reading the list of flagged words against what they know of the other languages: it found `borde` (Spanish "edge"), `medan` (the city), `gener` (Swedish "genes"), `sis` (an acronym), `moi`, `durant`, `maio`, `hagi` and `diez` (surnames, and a stopword drops every phrase that contains it), `dues` and `falls` (English), none of which any log row showed.
(2) **`PROVENANCE.md` has recorded since 2026-09-07 that `sea`, `tom`, `fin` and `laut` are kept out of the union for good, and the tool, which exists to apply that kind of ruling, accepted `laut` at 934 articles.** A refusal that lives only in a table fails the first time a batch re-proposes the word. `STANDING_REFUSALS` is now in the tool with no override, and a test reads the PROVENANCE heading and fails when the two sets differ in either direction. Rule: when a ruling says a word is never added, the tool that adds words must say so itself.
(3) **One shard is not the corpus.** Each shard is a language's top 5,000, so a cross-language check on one shard sees only the rows that language's articles produced; the batch used all 79 merged (`combine_logs.py`, one row per term, language and kind, reproducible to the hash in the batch comments). The merged log is still a sample.
