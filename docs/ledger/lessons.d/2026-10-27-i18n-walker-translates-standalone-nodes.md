## 2026-10-27 — the i18n walker translates any text node that EQUALS a key, so a raw server word is a defect only when it is joined into one node with other text

**What was found.** In an Arabic page the Maintenance state line read «الحالة: done» although `done` was a locale key in all twelve languages. `i18n.js` runs a MutationObserver walker that translates a text node when its trimmed value (inner whitespace normalised) equals a key, including nodes inserted later through `innerHTML` (outside a `[data-i18n-dyn]` subtree, and not inside SCRIPT, STYLE, TEXTAREA, CODE or PRE). The state word stood alone in a node in the no-progress case, and was translated for free; with a progress figure the same word shared one node with it (`done · 453 of 453 articles read`) and never matched. A sweep of the qualification files then called the bare English `<th>Edition</th>`, `<button>Pause</button>` and "No offline downloads." in `app-map.js` a clear defect, from reading the renderer alone; they are translated by the walker, and the claim was retracted before it reached a PR.

**The rules.**

1. **Before calling an unkeyed literal a defect, read what translates it.** A word alone in a node, with a key, is translated; a word joined into one node with other text, or one without a key, is not. Name which case you are in, and say it is read from `i18n.js` when it was not measured in a browser.
2. **The fix for a joined word is a closed map through `t()` that shows an unknown word exactly as the server sent it** (`_maintStateLabel` and `_wxVerdictLabel`, both guarded against inherited names such as `toString`; `kwKindLabel` is the same shape but unguarded, which is safe only because the server limits kinds to `_VALID_KINDS`), never a match on the English sentence.
3. **An identifier or a user-defined open set is shown as sent on purpose** (a Wikimedia dump file name, an AI keyword kind set by a custom prompt, an annotation kind): it has no closed list to map, and mapping a subset would mislabel the rest.
4. **A census ratchet is the cheap guard:** `tests/test_raw_token_labels.py` pins, per file, the count of `esc(x.state|status|kind)` so a new raw print fails and forces the decision above.
