## 2026-10-28 — A guard that names only the shapes found so far finds only those shapes: the os-patch guard now reads aliases, `os.path`, keyword forms, `patch.multiple`, assignments and every file under tests/ (R351 follow-on, R371)

**What was found.** The guard of #1602 (`tests/test_os_patches_are_scoped.py`) listed its own blind spots in the sweep's lesson; this closes them, test-only.
1. **`os.path` is a process-wide module too.** `monkeypatch.setattr(os.path, "getsize", f)` replaces `posixpath.getsize` for every caller, the runner included. The one site (`tests/test_vacuum_space_preflight.py`) now goes through `scope_os_path(monkeypatch, module, getsize=f)` in `tests/os_scope.py`, which binds `module.os.path` to a namespace that answers the replaced names and hands the rest to the real `os.path`; a second `scope_os` or `scope_os_path` on the module adds to it.
2. **The scanner now reads:** names bound to `os` (`import os as _os`) and to `os.path` (`import os.path as osp`, `from os import path as P`, `import posixpath as pp`), `posixpath`/`ntpath`/`genericpath` by name, `os.path` spelled through any attribute chain, the `target=` keyword of `setattr`/`delattr`/`patch.object`, `patch.multiple` with an object or a string target, string targets of `setattr`, `delattr` and `patch` ending `os.<name>`, `os.path.<name>` or `posixpath.<name>`, and plain, augmented, annotated assignment and `del` of an attribute of those modules. It pins every shape on the exact line (39 parametrized cases, 9 of them negative).
3. **It scans every Python file under `tests/`** (helpers, `conftest.py`, `scale/`), not `test_*.py` at the top level. That found one hit the old scan could not see: `tests/torture_helper.py` replaces `os.replace` in a CHILD process that kills itself at the swap boundary; it is allowlisted with that reason (nothing else runs in that process, and it never runs inside pytest).

**Measured, not assumed.** Run against main before the vacuum fix, the wider guard flags exactly two places in 1,535 files: `test_vacuum_space_preflight.py:551` (fixed here) and `torture_helper.py:207` (allowlisted). Every other file is unchanged, so the earlier count of zero other sites holds. A mutant per blind spot (no aliases, no `os.path`, no keyword arguments, no `patch.multiple`, no assignments, top-level glob only, no string `os.path` targets) each turns a test red; the top-level-glob mutant survived the parametrized cases and is caught by the coverage test added for it.

**Rule.** A scanner for a class of defect is pinned per shape on the exact line AND on the set of files it reads; a narrowing of either must turn a test red.

**Folded from the Opus read.** The dotted-string form of `delattr` (`monkeypatch.delattr("os.statvfs")`, the shape `hide_os` exists for) was missed; now flagged, two cases added. The read re-measured the count (2 in 1,535 files) and showed the vacuum conversion is not vacuous (6 of its tests fail with the replacement removed).

**Not covered, stated.** Local rebinding (`_o = os; monkeypatch.setattr(_o, ...)`), tuple assignment, `sys.modules["os"]`, `vars(os)`, an aliased `patch` (`from unittest.mock import patch as mp`), `mocker.spy(os, ...)`; none occurs in `tests/` today. The assignment rule is conservative: any `<x>.os.<attr> = ...` is flagged, so a fake platform object built as `SimpleNamespace(os=...)` and assigned into would need an allowlist entry or a rename.

**Also not covered.** `os.environ`, `shutil.disk_usage`, `tempfile`, `builtins`/`io` and other stdlib modules patched process-wide are different shapes and are not part of this guard. A function imported by name (`from os import replace`) and patched on the importing module is a scoped patch and is allowed.
