## 2026-10-12 — A TABLE CAN BE CUT OFF INSIDE ITS OWN SCROLL FRAME WHILE THE PAGE SHOWS NO HORIZONTAL SCROLL (row F analytics 4-5 look, PR #1340, `src/static/app.css`, `scripts/analytics45_look.py`)

The two cross-edition tables sit in `.wiki-table-wrap { overflow-x: auto }`. At 390 px they were 340 and 364 px of content in a 316 px frame (342 and 330 in Arabic), so the last column (the figure the table is for) was clipped behind a scroll with no mark that it scrolled, and the check every earlier walk ran, `document.documentElement.scrollWidth <= innerWidth`, passed, because the overflow belongs to the wrap and never reaches the page. **Measure the frame, not the page:** `wrap.scrollWidth <= wrap.clientWidth` for every `overflow-x: auto` wrapper a surface draws, at the narrowest width. The look reads the frame and the narrowest the table can be drawn (width forced to 1 px) into its record as a HEADROOM, because `scrollWidth <= clientWidth` is true for any table that fits and says nothing about by how much: 24 and 48 px over in English before the fix (26 and 14 in Arabic), +62/+56 px after at 390 px. **The first fix, tighter cell padding, fitted at 390 px with +1 px to spare and failed at 360 px (-29) and 320 px (-69); a fix measured at one width is a claim about that width.** Its judges are shown able to fail by `mutation_checks.py`, which serves the page a broken copy of one file at a time (a count drawn as `0`, a reload removed, a drop-down redrawn with the old value, the CSS removed) and needs the named check to fail. Two more facts from the same run. The generic drop-down judge (`csp_sweep.sweep_selects`) read a pick that DID change the table as `dom`/`none` in 2 of 48 runs, because its pre-pick idle sample caught a background request: a drop-down whose effect matters wants an explicit check of the thing it must change, beside the generic one. And a page that REDRAWS a select on every pick hands back a new element whose value is its own echo of the server's answer: the judge now marks the control before the pick and finds it again by node identity (`rebuilt` in the row), reading the pick from the control a person sees and again after 700 ms, instead of a rule («a rebuilt control counts as unread») the code did not enforce.
