## 2026-10-16 — a refusal is named where it surfaces: tests with the failure a real getter raises, an exception raised outside the handler, and records that can be found (PR #1401)

**What was found.** The QID label resolver recorded every failed lookup as `label_not_resolved`, including a lookup the host list refused (`RedirectRefused`), one refused because protected mode had no proxy (`TransportUnavailable`) and one the kill switch refused during the ten-second sleep; the Ollama installer's `api.github.com` lookup was the one fixed endpoint without a list. The independent read of the fix found the new tests could not tell any of them from a network failure.

**The rules.**
1. **A test's "ordinary failure" has to be the exception a real getter raises.** The table fetcher raised `RuntimeError("not found")`; real getters raise `requests.ConnectionError` or `Timeout`, and `RedirectRefused`, `TransportUnavailable`, `ConnectionError` and `Timeout` are ALL `requests.RequestException`s. A mutant that caught `RequestException` instead of `RedirectRefused` kept every test green, and in production would have called every dropped connection a refusal. Give each clause a test that feeds it each sibling class (connection, timeout, HTTP, other) and asserts the clause did not fire.
2. **A catch clause for a subclass goes BEFORE the generic one, and a subclass of `ConnectionError` is the place that order is silently wrong.** `TransportUnavailable` IS a `ConnectionError`; behind a generic `except Exception` it is `label_not_resolved`. Name each refusal before the generic clause and test it through the generic path's absence.
3. **Raise the user-facing exception OUTSIDE the `except` block.** `raise X() from None` inside the handler leaves `__context__` set (it is only hidden from the formatter); a flag set in the handler and a `raise` after it leaves neither a cause nor a context, and a test can assert both are `None`. Log the class name only.
4. **A sink test lists the record attributes the app writes, not only the ones `caplog.text` shows.** `errorlog._JsonlErrorHandler` writes `record.scrubbed_traceback` into the debug bundle; a mutant adding it to the warning's `extra` survived a test that read `exc_info`, `exc_text` and the formatted chain. And one parametrized case must use a refusal whose OWN text names the target, or the test is about the refusal's wording, not about the installer.
5. **Check the kill switch AFTER the sleep, and name a fetch it refused.** A check placed before the polite sleep lets the next fetch find out, and the generic clause records the row as an unresolved label (invariant #14e's corollary: a refusal by the kill switch is named as such). The fetch's own `NetworkBlocked` / `AirplaneModeError` is caught too, for the window between the check and the socket.
6. **Index the de-duplicated list when you slice the rest of it.** `list(qids)[i:]` indexed the raw list with the de-duplicated position, so two sources named `Q1` and a mid-run kill switch left `Q1` both labelled and declined. Iterate one `order = list(dict.fromkeys(...))` everywhere.
7. **A refusal sentence says what the list does, not what the common case is.** `refuse_unlisted_host` also refuses plain http on the SAME host, another port and credentials, so "redirected to another host" was false for a 302 to `http://api.github.com/...`; the sentence now says "somewhere this app does not follow", with a test for the same-host plain-http case.
8. **A queue entry nothing can find is not a record, and prose about what a change would do is checked against the handler.** `scripts/planned.py` keeps an open-queue entry only if its body carries one of its markers (STILL OPEN, NOT BUILT, PENDING ...); "KNOWN, NOT FIXED" had none, so a session about to edit `_default_get_bytes` was told nothing. Run `python scripts/planned.py <path>` after writing the entry. The same entry said a list on the asset download would "fail with the named refusal"; that download has no `RedirectRefused` handler, so it would be a generic 500, and the entry now lists the handler as part of closing it.
