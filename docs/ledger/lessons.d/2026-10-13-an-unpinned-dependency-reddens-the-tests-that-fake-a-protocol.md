## 2026-10-13 — an unpinned dependency reddens the tests that fake a protocol

`ci.yml` installs the web stack unpinned (`pip install -e .[...]`), so a release that lands between two pushes changes what a PR is tested against with no code change in it. Starlette 1.8.0 did exactly that on 2026-10-13: `tests/test_sources_route_and_compression.py::test_gzip_actually_shrinks_the_wire_bytes` went red on both Linux jobs of a PR that touched nothing it reads, and by the same token on every PR cut from the same base. The local venv (starlette 1.7.0) passed 9 of 9, and a scratch install of 1.8.0 on `PYTHONPATH` failed it 3 of 3, which is how a "flake" was told from a drift: a failure that reproduces on one version and not on another is a version, and the cheap proof is installing the newest release into a scratch directory (`pip install --no-deps --target`) and running the one file.

The cause was the test's own stand-in, not the app. The raw ASGI helper's `receive()` answered `http.request` on every call, which no server does: a server hands the request over once and then waits until the client is gone. Starlette's `BaseHTTPMiddleware` had tolerated the second call; 1.8.0 raises `Unexpected message received: http.request`. The rule it gives: **a hand-written protocol endpoint in a test follows the protocol, including what it does after the first message**; here `receive()` gives the request once, waits until the response body is complete, then answers `http.disconnect`. A test double that is more permissive than the real peer passes today and goes red the day a dependency starts checking.

The same pass found a second host dependence in a test written the same week: the probe text of `inference_capability` lands in `warnings` on a machine with 4 cores and 6 GB or more and in `reason` on one under that floor, so two tests that read `warnings` only passed on the CI runner and the author's machine and would fail on a small one. Forcing `os.cpu_count` to 2 shows both branches in one command; the tests now search the whole capability record.
