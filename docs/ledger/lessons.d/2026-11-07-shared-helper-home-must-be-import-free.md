## 2026-11-07 — A shared helper's home must cost nothing to import; a duplicate scan by body must ignore the signature (A-036, R446)

**Where not to put it.** The obvious home for a helper shared by monitoring, ingest, analytics and briefing modules is `src/utils/`. It is the wrong one: `src/utils/__init__.py` imports `security.py`, which imports `bleach` and `src.monitoring.secret_scrub` (measured: `python -X importtime -c "import src.utils.interrupts"` ≈ 0.87 s, of which `src.utils.security` is 0.34 s). A 14-line recursion in `src/ingest/tor_throughput.py` would have taken on that cost and an import edge from ingest into monitoring. The helpers live in `src/shared.py`, a stdlib-only TOP-LEVEL module with no package `__init__`, and a test pins that it imports nothing else, so the next addition cannot quietly turn it into the thing it was put there to avoid.

**Names that tests patch stay as names.** `tests/` monkeypatch `card_audit._report_dir` and the diagnostics bundle's `_all_diagnostics_dir`. Moving the body to `src.paths.diagnostics_dir` and importing it under the old name (`from src.paths import diagnostics_dir as _report_dir`) keeps every patch and every `from src.briefing.card_audit import _report_dir` working, because callers resolve the module global at call time. The shared function itself looks up `data_dir` in `src.paths` at call time, so a test that patches `src.paths.data_dir` still redirects all three.

**Finding every copy.** The audit's scan of byte-identical bodies reported `_report_dir` ×2; there were three, because `monitoring/p0_validation.py` writes the same body with a `-> Path` annotation and a signature-sensitive comparison split it from the group. When counting copies of a helper, compare the BODY (the AST of the statements) and report the signature difference separately.

**Rule.** (1) A shared home is chosen by what importing it costs, not by what is nearest. (2) After a fold, a structure test must assert both that the shared name is defined once and that every old private name is defined nowhere; a behaviour test alone stays green the day a copy is pasted back. (3) Count copies by body.
