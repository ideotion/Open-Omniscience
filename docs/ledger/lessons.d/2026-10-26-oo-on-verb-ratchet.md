## 2026-10-26 — a ratchet that finds dangerous names by their first letters misses the ones that put the verb in the middle

**Found (read of the A-004/A-011 bundle, 0.5.0 audit).** The test that kept destructive handlers from running on an injected zero-click binding matched `^(delete|remove|secure|panic|uninstall|shutdown)`. Every handler the bundle had fixed started with one of those words, so the ratchet agreed with the fix and said nothing about `sgRemoveMember`, `kxRemoveTag`, `familyResetGroup`, `disableUnmanagedLanguages`, `jobCancel` and `excludeKeyword`, which erase or stop things, and `lawSetWatched(id, false)`, which DELETEs. A prefix is how the author thinks of the names that were in front of them; it is not how the next author names a handler.

**Rule.** (1) Find a dangerous name by the words inside it, split on camelCase boundaries, not by its start. (2) A name that carries such a word has to land in exactly one place: it confirms in its own body, it is in the gesture-only set, or it is on a short list of names that touch only this tab's view or this browser's localStorage, each with a written reason. A new name that is in none of them fails the test and is named in the failure. (3) Give the exemption list teeth: a test that every entry is a real verb-named action (no dead entries), is not also gated, and still makes no POST/PUT/DELETE/PATCH request in its own body. (4) Pin the finder itself with the names it used to miss, and with plain words it must not catch (`removedAll`, `descendants`), so a regex edit cannot quietly return it to the old blindness.

**Limits.** A destructive half that lives in an argument rather than in the name (`lawSetWatched(id, false)`) has no verb to find; it is listed by name and a future name of that shape is not found. A view-only name that reaches the server through a helper it calls is not seen by the body check. The guard is still a gesture, not an intent: an injected overlay or accesskey turns a person's next click into a trusted click on the control. The generalised per-event allowlist (audit A-023/A-024) is the real fix and stays a proposal.
