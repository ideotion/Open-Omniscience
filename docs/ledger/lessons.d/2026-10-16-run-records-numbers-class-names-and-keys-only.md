## 2026-10-16 — a durable run record is written OPEN at the start, closed at every branch, and takes only numbers, class names and keys of fixed tables; a refusal is a run that never existed (PR #1421)

**What was found.** The Diagnostics zip kept the runs that opened a run journal (`run-journal.json`, the last twenty, `runlog.begin` first) and nothing for the three things that happen BEFORE or WITHOUT one: a start that is refused (`start_backup` raises on a missing passphrase, a destination that cannot be made, a path that is not a folder; every start raises on a job already running), a worker killed in the middle of a backup (the run journal's lines are flushed on a schedule, and a kill leaves whatever was flushed), and a backup that ended "ok" with its summary file not written (`write_summary_for_export_job` logs and returns None). The free bytes of the volume the run was writing to were nowhere, and a restore queue that fails eight times pushed everything older out of a single ring.

**The rules.**
1. **Write the record OPEN at the start and close it at each branch, with a `finally` net.** `storage_events.run_started` records the run with a key, `run_ended` closes it; a process killed in the middle leaves "started, never ended" (the next read marks it "the process ended while this was open"), and the `finally` calls `run_ended(note, "ended-without-a-recorded-outcome")`, a no-op once an outcome was written, so a `BaseException` that no `except Exception` takes still closes it (tested with one).
2. **A refusal before any run exists is recorded at the raise, closed in one write (`run_refused`, `ran: false`).** The start methods raise before `runlog.begin`; a record made only in the worker would never see them. Every `raise` in a `start_*` is preceded by one (an AST pin counts them), and the one rejection every start shares takes the kind as an argument so the record names the kind that asked.
3. **The sink takes numbers, flags, class names and keys of tables, and drops everything else; the hooks are pinned to hand nothing else.** `_run_fields` keeps a fact only if its NAME is in the table for its kind (number, flag, class, one of five read-back states); `_class_name` keeps a value only if it is shaped like a class name (else the fixed marker); a refusal is a KEY and the journal writes the sentence. An AST test then reads every hook call in `volume_job.py` and `export_summary.py` and fails on `failure=` that is not `type(<name>).__name__`, on a `**` mapping, on an outcome that is not a constant of the table and on a fact name the sink does not know. A one-word message passes the SHAPE check, so the pin on the call sites is the real guard.
4. **Caps per kind of run, not between them.** Three journal kinds (`run_export`, `run_import`, `run_verify`, ten each): a restore queue of eight items that all fail must not push last week's failed backup out; `total` still counts every run (a test sends thirteen restores and one backup).
5. **An unreadable figure is absent, never zero.** `free_bytes_of` answers `None` and the field is not written (a `0` reads as a full drive); it is read AFTER the run is written open, so a stat that hangs on a dead mount leaves the run open, which is the fact. The restore reads the data folder's free bytes (where it stages) only after the "already merged" skip, so a restore that writes nothing does not stat a drive.
6. **The budget is the widest event times the cap, with EVERY field present at once.** The fixture fills each run with every fact at a large value and the longest class name and sentence (734 bytes; a real run is 146 to 299); the member went from 86,658 to 109,375 bytes at full retention and the row from 90,000 to 115,000. The "hard ceiling" pin (250,000) was the then-current ceiling of six kinds, not the protection: it became 300,000 for nine, and the line beside it (a tenth of the zip) is the pin that does not move.
7. **The sink sweep reads a PARAMETER named `error`, `exc` or `exception` as a caught exception.** The class-name parameter is `failure` (the stored field is still `error`), and the six `_internal_failure(..., exc)` handlers that every journal function has are allowance lines keyed by function and exact text, like the rest of the file.
8. **A hook that takes a `**` mapping defeats the AST pin.** The verify hook first passed `**({"set_ok": ok} if ... else {})`; it now passes `set_ok=<value or None>` and the sink drops a non-bool.

**Stated limits.** Three paths open a run journal line and write no storage event: the legacy single-file restore (`restore_legacy_path`, `runlog.run`), the folder backup, restore and verify (`folder_backup.py`, `runlog.run`) and the newsletter import (`import_job.py`, `runlog.begin`); the shape check accepts a one-word message; an older build reading a file with these kinds drops them on its next write.
