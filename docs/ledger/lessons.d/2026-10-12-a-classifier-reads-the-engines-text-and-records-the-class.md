## 2026-10-12 — A CLASSIFIER READS THE ENGINE'S TEXT AND RECORDS THE CLASS, NEVER THE LINE (E3 fold 12, the coordinator's check of fold 11)

`damage.corruption_of` is the one place the damaged-database work reads a driver's own words: it takes the first line of the driver's error to tell a damaged page ("database disk image is malformed") from a damaged schema ("malformed database schema (name) - ...") from a driver that gave a code and no usual line. It also RECORDED that line (cut at 160 characters), in the incident record `data/database-damage.json`, which rides the diagnostics bundle, and as the reason of the verdict a per-table check files. SQLite words some corruption errors with the name of the schema object and a fragment of its definition, and the record is the one thing in the bundle that no code of ours wrote.

The rule: **classify on the raw line, record the class.** The record now carries one of three FIXED labels (`CORRUPT_IMAGE`, `CORRUPT_SCHEMA`, `CORRUPT_OTHER`, chosen by what the line starts with) and the exception's class name (`driver_class`); no part of the driver's line goes on, scrubbed or not. A scrub is the right tool where the text must be kept (a failure reason the operator needs word for word); where the class answers the question the record exists for, the class is the whole record, and there is nothing left to scrub or to forget to scrub in a new form.

The test that holds it feeds a driver error carrying a marker in each place SQLite puts text (the page, the schema object's name, the fragment after it, a second line, a source line, a code with unusual text) and asserts that the marker is in none of: the dict `corruption_of` returns, the JSON file the registry wrote, and the reason of `verify.classify_error`; and that each class gets its own label (a mutant that collapses the labels, one that returns the raw line from either branch, and one that drops `driver_class` are all killed). A guard that only passed the ordinary "database disk image is malformed" would pass against an implementation that records the whole line, because for that text the label and the line are the same string: the markers are the test.
