## 2026-10-13 — a source-grep test passes while the branch it pins is unreachable, and a three-letter code walks around a gate keyed on two letters

**(1) The caveat sat on a path an empty ring never takes.** The T5 layout PR (#1377) made the "every keyword of this group is hidden by the stoplist" note a translated template and wired it into the ring map's `ooMap(...)` call. An empty ring has `countries: []`, so `showRingMap` takes the `if (!shownCountries)` branch, which never calls `ooMap`: the translated sentence could never appear, and the screen still read "No located sources for this concept yet", the very misreading the note exists to stop. The test that pinned it grepped the JavaScript for `tf(d.caveat_i18n, d.caveat_vars)` and passed. An independent read of the diff found it, the PR was fixed (the empty state itself carries the caveat), and the follow-up replaced the grep with `tests/ring_caveat_node_test.js`: `showRingMap` EXTRACTED from the shipped source and run against the four payload shapes the endpoint sends (all hidden, none indexed, unlocated-only, located; a fifth, keywords without mention rows, was added after the read), with the real locale files and the real `tf()`, asserting the rendered HTML in every locale. **A test that names a call in the source proves the call is written, not that any input reaches it. For a display path, run the real function on the payload that exercises it and read what the reader would see; then delete the wiring and check the test fails.**

**(2) A gate keyed on a two-letter code is walked around by the three-letter spelling.** `TWICE_READ = {vi, ko, as, tl}` was checked with the exact `--language` string, so `--language kor` (or verdict rows tagged `kor`) skipped the marker gate and wrote `kor.yml`, which the loader unions for every language. The primary code is now normalised through `TWICE_READ_ALIASES` (kor, vie, tgl, asm, and `fil` for Filipino) before the check, the converter's `--check-tool` lifts the table and runs its matrix for every alias, a spelling of the same language in a verdict row or a `--language` is refused rather than skipped, and tests fail when the table or either refusal is removed. **When a safety rule is keyed on a code, enumerate the other spellings of that code the same tool accepts, and make the check and the matrix cover them.**
