## 2026-11-04 — a grouping key no parser can read is declared by the catalogue, and a write that runs every pass must not treat "nobody said" as a value (PR #1716)

**What was found.** The law lane aligns language versions of one law by an identity, formed from the number an adapter read out of the body, else from the document's own URL. A treaty page states no number a parser can trust, so the only key left was the URL, which differs per language, and the alignment the model was built for (Q908) never happened for the one kind of instrument published in several languages by construction. The honest key is a statement by the person who knows which URLs are one treaty, written where they already write the URLs: the catalogue row. It is looked up by the row's own `(jurisdiction, url)` by exact equality (a host match would hand one declaration to everything the host serves), never derived from the URL, and a row that declares nothing is recorded exactly as before.

**The rule that makes a declaration safe.** (1) One function checks it, and the validator, the test over the committed files and the tracker all call that function, so what CI accepts is what the tracker applies. (2) A declaration with ANY problem is treated as absent as a whole: applying the `doc_type` while dropping the identity files a language version under the wrong law with nothing to say so, where an ungrouped one is visible. (3) Rows that declare one law are checked against each other (one `doc_type`, at most one `original`), because the group reader would otherwise resolve the contradiction silently with a log line. (4) The jurisdiction is part of the key: the same declared value in INT and in another jurisdiction is two laws.

**The second finding, on the same path.** `record_document` runs on every tracking pass and passed `doc_type="unspecified"` and `translation_kind="unrecorded"` every time; `ensure_identity` and `register_document` wrote them over whatever was recorded. The docstrings promise that a later pass never erases what an earlier one read and that an operator can correct what the app left unrecorded, and the next poll undid both. The cause is general: a value that means "nobody said" looks like a value when it is a constant in a write that runs on a schedule. The fix is that an incoming "nobody said" never replaces a recorded value and saying something still changes it. When reviewing a function that is called on every pass, ask for each argument whether its default can arrive as data.

**A test-data trap.** The synthetic Chinese body was first 115 characters, under the tracker's 200-character floor, and was recorded as "no usable text extracted": the floor counts characters, which is about four times less content for CJK than for Latin script. A fixture in a non-Latin script has to be checked against the floor, not assumed to clear it; the floor itself was left alone (a threshold change is a behaviour ruling) and is recorded as an observation.

**What is NOT known.** Nothing here was read from a real treaty site: the fixtures are invented and the live URLs wait on the operator. The shape of a real UN Treaty Collection or WIPO Lex page, its licence and its robots rules are unverified.
