## 2026-10-17 — A SAMPLE THAT MUST SURVIVE A RESUME IS A HASH ORDER, NOT A RESERVOIR; A "STRIP THE CLOSING MARKS" REGEX ON USER TEXT IS QUADRATIC, SO SCAN FROM THE END (PR #1440, PR #1445)

(1) **The sample.** An operator judges a rule from rows, not counts, and a quarantine run is chunked and resumable. A reservoir keyed on a running count reshuffles after a resume and depends on chunk order. Keeping the K candidates with the smallest `sha256(f"{signal}:{id}")` depends only on (signal, id): the same corpus gives the same rows in any chunk order and across pause, resume and restart, and merging a chunk is "union, sort by rank, cut to K". State holds ids only (a test greps the state file for a title, a URL and body text); titles and URLs are joined at read time. K = 20 is a display sample; measured with the manager's own `_save`: 15 signals x 20 seven-digit ids add 3,063 bytes to an 868-byte state file. The plan had guessed "under 1 KB"; the measurement said three times that, which is why the size claim is measured before it is written.

(2) **The regex (found by the independent reads of #1440).** `(?:\s*\[[^\]]{1,20}\]|[\s»"”)])+$` to strip trailing closing marks backtracked CUBICALLY on a long run of whitespace (3,000 spaces: 10 s through `stub_verdict`; 4,000: 23 s) because `\s*` overlaps `\s` in the class. Dropping the `\s*` made it QUADRATIC, not linear: `[class]+$` tried from every start position still rescans the run (40,000 spaces: about 87 s inside the test). Only a right-to-left scan (`rstrip(chars)` plus one bracketed-tag step) is linear: 10k / 40k / 160k spaces took 0.1 / 0.3 / 1.3 ms. A thin body can still hold long whitespace runs, and this code runs inside a background job over millions of rows.

(3) **How to test it without a clock.** Compare the same function on 10k and 160k of input, best of three each, and bound the ratio at 64x: linear is about 16x, quadratic about 256x, cubic about 4,096x, so the bound separates them with margin and needs no wall-clock limit. A "< 2 s" bound flakes on a loaded runner; a ratio of 4x (10k vs 40k) hides quadratic (16x) behind a loose bound, which is exactly the shape that was shipped for one commit.

(4) **A word cap cannot separate a headline from a brief.** The paywall rule first spared a body with more than 8 non-prompt words; a 9-word headline (the real Fjordabladet page) then slipped out and a 12-word brief was caught only by luck of the cap. A structural rule (the rest of the body contains a sentence: at least N words in total with a paragraph that ends in terminal punctuation after closing marks) separates them, and its numbers (6 words, a sentence line of 4) are named constants that say they are fitted to two data points and that the dry-run samples should move them.
