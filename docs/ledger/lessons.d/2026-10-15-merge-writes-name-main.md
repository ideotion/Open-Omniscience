## 2026-10-15 — a class of "left unqualified rather than churned" is closed by a scan, not by remembering to qualify

**(1) "Qualify one when its handler is next edited" never closes a class; a scan over the module's strings does.** Sixty-four writes in `src/backup/merge.py` named no schema for weeks, on the reasoning that `init_db` makes the hostile case impossible. The rule that finishes it is a source scan (`tests/test_merge_writes_name_main.py`) that FAILS CLOSED: it reads the SQL at every `execute`/`executemany`/`executescript` (through `text()`, concatenation, `%`, `.format`, f-strings, conditionals and a name's assignments) and at every helper that hands a parameter on (found by fixpoint, not listed by hand), and a statement it cannot read is a problem unless the allowlist gives a reason (and a dead entry fails). Planted cases, one per shape (upsert, `REPLACE INTO`, `INSERT OR REPLACE`, script, built, `WITH ... INSERT`, helper caller, unreadable), prove it fails when it should and passes the qualified spellings; run on the module as it was it reports 127 sites. A scan that matches nothing proves nothing, so a floor on how many writes it reads is pinned too.

**(2) The cheap mechanical change needed the same two proofs as any other.** Line-targeted regex edits (the scan lists the lines, the edit touches only those) left 64 changed lines and no others (`git diff --stat`), `main.{table}` inside an f-string and `UPDATE main.articles AS m` are valid SQLite, and the four FTS5 command inserts accept `main.article_fts(article_fts, rank)`. What the scan does NOT read is stated in the OPEN_QUEUE entry: a statement assembled by concatenation or sent by the ORM, and `CREATE TABLE IF NOT EXISTS` on standalone connections.

**(3) A CI pin that searches a whole job's text proves less than the line it names.** The floor-leg export (`OO_EXPECT_SQLCIPHER_ENGINE`) is now required in the `env:` of the one step that runs pytest; moved to the job level it still reached pytest but the test went red, which is the cost of asking for the narrower fact.
