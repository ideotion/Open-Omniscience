**Rules.**
1. **A test of a fault is not proved by passing.** Name the line the fault must reach (a call count, a list of what was asked) and assert it, unless the test is a guard whose expected count is zero (R351 rule 2, applied).
2. **A stub that fails on every call fails on the first, and the first is often before the code under test starts.** Answer the earlier questions for real and fail the one the test is about.
3. **Prove the vacuity before the fix:** run the test with the behaviour it names removed. If it stays green, say so in the record; if it goes red, the test was never vacuous and nothing is changed.
