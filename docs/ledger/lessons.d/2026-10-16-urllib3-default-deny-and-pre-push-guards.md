## 2026-10-16 — a scrubber for text you do not write is default-deny over a table the installed library proves, and the checks before a first push are picked by what changed, not by what you remember (PR #1420)

**What was found.** The filter #1414 put on `urllib3`'s loggers rewrote the target argument of the log lines it knew and let everything else through, on four loggers, from the shapes of one release. That is allow-by-default for text the app does not write: a release that adds a log call, a logger that is not one of the four (`urllib3` defines nine), or a template with the target formatted into a longer string would leak the signed storage address with every test green, and nothing in the repository said which `urllib3` the filter had been read from. Separately, the push of #1414 was red in CI for `tests/test_sink_sweep_records.py`, a file `main` had added a day earlier and the merge had brought in; the branch had run the tests it changed and the tests about its module. A CI cycle here is about fifty-five minutes.

**The rules.**
1. **A scrubber for another library's text withholds what it does not recognise.** `SHAPES` keys `(logger, message template)` to the source text of each argument and the positions that carry a target. A record with no entry, another number of arguments, a non-tuple `args` or a message that is not text has its message replaced whole: logger and level kept, the exception's class name kept, arguments, `exc_info`, `exc_text` and `stack_info` gone, and the record is never dropped (a dropped record hides the very failure the journal exists to show). Doing it twice leaves the first result (`_is_withheld_message`).
2. **A filter must never raise.** `SHAPES.get((name, msg))` with an unhashable message (a list, a dict) raises `TypeError` inside `Logger.filter`; the lookup is only made for `str`, and the test passes `[ConnectionError, list, dict, None, 7]` as messages (a surviving mutant found it).
3. **The table is proved against the INSTALLED library, by AST, not by a real socket alone.** The test reads every `log.<level>(...)` call of the installed `urllib3` and fails by name on a call that is not in the table, an argument whose source text differs, a table entry the library no longer has, and a module logger that is not in `LOGGERS`. The real-socket tests stay (they show a shape the AST reader cannot), and each also asserts the withheld sentence is absent, so a known shape that falls through to the default is a failure and not a pass.
4. **Bound the dependency by what you read.** `pyproject.toml` has `urllib3>=2.7.0,<2.9`: the floor and the verified release are the two read (identical templates and arguments), the ceiling is the first release NOT read. The registry entry `urllib3-log-shapes` (floor, verified, ceiling, `upstream_check`, freshness) and a freshness test that ties the pyproject text to the entry make an upgrade a decision with a checklist (`EXTERNAL_DEPENDENCIES.md`) instead of a `pip install -U` that moves the logging under a filter that has never seen it. The lock file's `via` comment names the project as a requirer.
5. **State what a filter on a logger cannot see.** A filter on a logger runs for the records that logger CREATES, so a child logger someone adds under those names is uncovered; and the traceback of a KNOWN shape is left as logged, because the one logged today carries the server's header text. Both are written in the module docstring, `SECURITY.md` and the queue entry, not left for the next reader to find.
6. **Pick the pre-push checks from the diff, with a tool, and test the tool.** `scripts/guards_for_diff.py` picks (a) the tests `main` added since the branch left it, found through the merges INTO the branch (for each extra parent `P` of a merge `M`, `merge-base(M^1, P)..P` on `tests/`; diffing `M^1` against `P` instead shows the branch's own edits as `main`'s, which a test with a branch-only edit to a shared test file pins), (b) the tests the branch changed, untracked ones included, (c) the test files that walk the tree (`rglob("*.py")`, `os.walk`, `glob` over `src`), then the blocking ruff lane and the style ratchet with its ceiling READ from `ci.yml`, and it says when the base is ahead of the branch (a green run of a tree that is not the one that will merge). Its selection is tested on a throwaway git repository (21 mutants, 20 killed, 1 equivalent). Pytest collects `test_*.py` AND `*_test.py` at any depth under `tests/` (`tests/scale/` exists): a predicate that took depth one only was a surviving mutant.
