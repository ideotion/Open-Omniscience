## 2026-10-16 — the QID label resolver names a refusal, a missing transport and the kill switch, and the Ollama installer's release lookup is held to api.github.com (PR #1401)

It now declines a `RedirectRefused` as `redirect_refused`, counted as `lookups_refused` with `refusal: "RedirectRefused"` (the class name, no address) when above 0, the same way `apply_source_types` counts `sources_refused`; a `TransportUnavailable` (protected mode with no usable proxy, a `ConnectionError`) as `transport_unavailable` for that row and the rest of the run, since the lookup was never sent and every later row would be refused the same way; and a fetch the kill switch refused as `network_refused`, with the kill-switch check moved AFTER the polite sleep and the rows to decline taken from the de-duplicated order (a resolved id could also be listed as declined). `admit_or_decline` takes the resolver's reasons, each with its own detail text, so the endpoint's `declined_rows` now also carry `wikidata_has_no_label` and `network_refused` (before, always `label_not_resolved`); nothing in `src/` or `src/static/` reads the old single reason, and no UI calls the endpoint.
