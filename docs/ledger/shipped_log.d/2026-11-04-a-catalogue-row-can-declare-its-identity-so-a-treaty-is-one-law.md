## 2026-11-04 — a catalogue row can declare its identity so a treaty is one law (v0.6.0 C-L2, PR #1716)

Row C slice S3 (Q908, Q901's note, Q902 d, Q930; coordinator ruling R420). A treaty is published in several languages by construction, and `lane_sync` could not align them: it keys a law on the number the adapter read out of the body and otherwise on the document's own URL (`local`), and a treaty page offers no number a parser can trust, so six language URLs were six unrelated `local` identities. A `documents:` row in `configs/legal_sources.yml` (or the generated file) may now declare `identity: {scheme, value}`, `doc_type` and `translation_kind`. `src/law/declared.py` (new, pure) checks a declaration (`declaration_problems`), reads it normalised (`declared_of`), finds it by the row's own `(jurisdiction, url)` by exact equality (`declared_for`) and checks the rows that declare one law against each other (`consistency_problems`: one `doc_type`, at most one `original`). `lane_sync.record_document` reads the catalogue once for both the declaration and the licence and records what the row states; a declared identity wins over a number the adapter read, so a document does not change identity between passes depending on whether a parse succeeded. A row that declares nothing is recorded exactly as before (the test compares the inputs for `None`, `Declared()` and no argument).

Rules the slice holds, each with a test that fails when it is dropped: the value is the operator's statement and is never derived from the URL; the scheme is the existing `act-number` (the model's closed vocabularies are unchanged, no schema change, no migration); a declaration the model refuses (unknown scheme, empty value, unknown key inside `identity`, `doc_type` outside the vocabulary or one of the four refused by name, `translation_kind` outside it, a jurisdiction that is not alpha-3 or INT) makes the WHOLE row undeclared with a warning rather than applying the half that parsed, and fails `scripts/validate_legal_catalog.py` and `tests/test_law_declared_identity.py` (which also reads both committed catalogues, vacuously today); the same declared value in INT and ZZZ is two laws; a neighbouring URL, a prefix and the same URL in another jurisdiction declare nothing for this one.

Two reset bugs found on the way, both on the every-pass write path. `ensure_identity` wrote `doc_type = kind` on an existing identity every call, and `record_document` always passed `unspecified`, so a recorded category went back to "nobody said" on the next pass. `register_document` did the same for `translation_kind` (always `unrecorded`) and for `translated_by` (always the argument, `None`): `set_translation_kind`'s own docstring says a correction is logged, and `lane_sync`'s says an operator can correct what the app left unrecorded, but the next tracking pass undid it. Now an incoming "nobody said" (`unspecified`, `unrecorded`, no translator) never replaces a recorded value, and saying something still changes it (logged). Three mutants of exactly the old code are killed.

Evidence. `tests/test_law_declared_identity.py` (31 tests, ~4.5 s) runs the real path end to end on a synthetic treaty: `register_documents` from `tests/fixtures/law/synthetic/treaty/catalogue.yml`, then `track_document` for six HTML bodies in `zxx-en, fr, es, ru, ar, zh` (one right-to-left, three non-Latin scripts) with no socket. Result: one `LawIdentity` (`act-number`, INT, `mtdsg:xviii-1`, `treaty`, `international`), six `LawDocumentMeta`, six separate baselines, the group reads the same from every member (original `zxx-en`, five others), `reader_payload` of each version lists the five others with their kinds, a second pass changes nothing. Negative space: a second declared treaty on the same host and an undeclared row stay apart (three identities); an undeclared row is `local`, `unspecified`, `unrecorded` as before; a misspelt scheme leaves the row `local` and logs it. Sixteen mutants were run; fifteen were killed, and the survivor (`source_for_url` given the loaded catalogue instead of re-reading it) is equivalent by construction, since both read the same file.

What is NOT done, stated. (1) NO live treaty ingestion: no UN Treaty Collection or WIPO Lex URL is in the tree, because neither host answers from the build sandbox and the brief asks for operator-verified URLs. The fixtures are invented (hosts on the reserved `.test` TLD, `zxx-*` tags, sentences written by the model and not reviewed by a native speaker). The slice's done-when, "one treaty ingested in six languages, aligned", is therefore shown on the synthetic treaty only. (2) No new host, no licence token, `docs/SECURITY.md` and `src/static/net-hosts.js` untouched.

Open operator items (R420). (a) Six verified language URLs of ONE UN treaty, with the robots and licence look, to put in the catalogue with a declared identity; `treaties.un.org` is already in the 260-host count and the law lane is a class lane. (b) WIPO Lex rows would add `wipolex.wipo.int`, which is NOT in the 260 (261, and `docs/SECURITY.md` plus `net-hosts.js` change together under their own enumeration tests). (c) `model.LICENCES` has no UN or WIPO token, so a treaty row inherits `unknown` until a ruling adds one. (d) WIPO Lex is typed `ip`: a treaty hosted there is category `ip`, and the C-L1 floor counts it in `non_law_documents`, crediting no country; whether a treaty hosted by an IP office should count is a ruling. (e) The UN treaties' texts are typically equally authentic, and the vocabulary has one `original` per group (`official` is a government's translation): the operator declares the kind per row or leaves it `unrecorded`; adding an "authentic text" kind would be a model ruling. (f) Observation, not changed: `track._MIN_TEXT` is 200 CHARACTERS, so a CJK page needs far less content than a Latin one to fall under it ("no usable text extracted"); the first draft of the synthetic `zh` body (115 characters) did exactly that. A real treaty is thousands of characters, but a short Chinese or Japanese document would read as empty.

Removing or changing a declaration re-files that language version on its next pass (the identity it left stays, with its other members).
